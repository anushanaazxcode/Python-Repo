# Text and Number Tools

## Project Overview

This Python application performs basic text and number analysis through user input.

The program:

- Counts the number of words in a sentence
- Finds the longest word in the sentence
- Reverses the entered sentence
- Checks whether a given number is prime

The project was built using Python and follows the requirement of using separate functions for each task.

## Features

### Text Analysis
- Word Count
- Longest Word Detection
- Sentence Reversal

### Number Analysis
- Prime Number Checker
